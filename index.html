📖 Quick Type Reference

Numeric Types (use magic numbers):
8 → uint8_t    16 → uint16_t    32 → uint32_t    64 → uint64_t
-8 → int8_t    -16 → int16_t    -32 → int32_t    -64 → int64_t
32.0 → float    64.0 → double
Any other integer → uint32_t (default)
Any other decimal → double (default)
String Enums (use pipe delimiter):
"success|failure|pending" → enum with values
// Generates: enum Status : uint8_t { STATUS_SUCCESS, STATUS_FAILURE, STATUS_PENDING };
Complex Types:
["item1", "item2"] → IStringIterator*
[123, 456] → IValueIterator*
[{...}, {...}] → Custom struct + iterator
{"key": "value"} → Nested struct
